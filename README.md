# Panchisco

## Descripción

Panchisco es una tienda online desarrollada como trabajo práctico de Seminario de programación. El objetivo del proyecto fue aplicar conceptos de HTML, CSS y, como principal, uso compartido de github para crear una página web funcional, organizada y adaptable a distintos dispositivos con un @media.

La página permite explorar diferentes productos, visualizar reseñas de clientes y comunicarse mediante un formulario de contacto.

## Secciones del sitio

### Inicio / index

La página principal presenta a Panchisco y ofrece una introducción a la marca. También incluye imágenes representativas y elementos que ayudan a mejorar la experiencia del usuario. Además de una descripción de nuestros productos y colaboradores.

### Productos

La sección de productos muestra las diferentes variedades de panchos disponibles. Cada producto se presenta mediante una tarjeta con imagen y nombre, organizadas de forma responsiva utilizando Flexbox.

Algunos de los productos incluidos son:

- Pancho 24 cm
- Pancho 1,2 m + 2 cm
- Pancho Doble
- Pancho Veggie
- Pancho Aesthetic
- Pancho Inverso

### Reseñas

Esta sección reúne opiniones de clientes sobre los productos ofrecidos. Las reseñas están distribuidas utilizando CSS Grid para lograr una presentación ordenada y visualmente atractiva.

### Contacto

Incluye un formulario que permite a los usuarios enviar consultas, sugerencias o comentarios. El envío de datos se realiza mediante Formspree.

## Características implementadas

- Estructura semántica con las etiquetas header, nav, main, section y footer.
- Menú de navegación interna entre las distintas secciones.
- Diseño responsivo para diferentes tamaños de pantalla.
- Uso de Flexbox en la sección de productos.
- Uso de Grid en la sección de reseñas.
- Implementación de Media Queries.
- Integración de Google Fonts.
- Formulario funcional mediante Formspree.
- Inclusión de contenido multimedia a través de imágenes.

## Tecnologías utilizadas

- HTML
- CSS
- Flexbox
- CSS Grid
- Media Queries
- Google Fonts
- Formspree
